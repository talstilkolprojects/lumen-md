# Public-eval fixtures — synthetic

Everything in this folder was written by hand for unit tests of the public
benchmark harness (src/eval/public, plan W11.H5). It is in the published
formats (UCD BidiCharacterTest/BidiTest) but it is **not** benchmark data and
no number measured on it is a result. Real data is downloaded into the
git-ignored eval/public/.data/ and results go to eval/results/.
