### RR30-1 (LOW, confirmed): a stream of a control file without `$` passes

**What passes:**
- `CLAUDE.md:stream`, `AGENTS.md:x`, `CLAUDE.MD:x` and `CLAUDE.md. :x` all pass `safeWriteTarget`. The rule refuses only `:$`, `::`, a trailing `:` and a drive prefix.
- On NTFS, such a write goes to an alternate data stream of the control file, and creates an empty control file if none exists.

**Mitigation:**
- The Windows native vault refuses any path segment containing `:` (`src-tauri/vault/src/lib.rs:97`), so the desktop app can't make this write.
- I did not check a backend that has Windows file semantics and keeps `:` (for example a browser folder on Windows).

**Fix:** match `AGENT_CONTROL_FILES`, and the dot-folder rule, on the part of each segment before its first `:`.
