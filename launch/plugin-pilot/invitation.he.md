# הזמנה: לבנות תוסף ראשון ל-Lumen (חצי שעה)

**נושא:** בקשה קטנה: לבנות תוסף ל-Lumen ולספר לי איפה נתקעת

היי [שם],

אני טל, ואני בונה את Lumen: עורך Markdown מקומי, בעברית קודם, עם קוד פתוח (https://github.com/talstilkol/lumen-md). הפתקים נשארים במכשיר, והאפליקציה עובדת גם בלי רשת.

ל-Lumen יש עכשיו מערכת תוספים בארגז חול (QuickJS): לתוסף אין גישה לרשת או לדף, רק ל-API של Lumen, ורק להרשאות שהמשתמש אישר. כדי לדעת אם זה באמת נוח למפתחים, אני מחפש חמישה מפתחים מחוץ לפרויקט שיבנו תוסף אחד כל אחד.

**מה אני מבקש:**
- לבנות תוסף קטן אחד עם `create-lumen-plugin`. המטרה היא תוסף ראשון שרץ בתוך חצי שעה.
- למדוד את הזמן בארבע נקודות (טופס מוכן מצורף).
- לכתוב לי מה האט אותך או בלבל אותך. כל תקלה הופכת למשימה אצלנו.

**מה צריך:** Node.js 18 ומעלה. אין `npm install`: לתבנית אין תלויות.

```bash
git clone https://github.com/talstilkol/lumen-md
node lumen-md/packages/create-lumen-plugin/bin.js my-plugin
cd my-plugin && npm run dev
```

אחר כך ב-Lumen ‏(https://lumen-md.vercel.app): גלריית התוספים ← מצב מפתחים ← התחברות.

**רעיונות, אם אין לך:** ספירת זמן קריאה לפתק, המרת תאריכים עבריים ולועזיים, בלוק קוד שמצייר ציר זמן, ניקוי טקסט שהודבק מ-Word, רשימת קישורים שבורים בפתק.
