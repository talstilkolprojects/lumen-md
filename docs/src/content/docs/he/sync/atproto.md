Lumen יכול לפרסם פתק **בחשבון ה-AT Protocol שלכם** (הרשת שמאחורי Bluesky) כמסמך
[Standard.site](https://standard.site). קוראים כמו Leaflet מציגים אותו כמאמר, ו-Bluesky מציג
תצוגה מקדימה עשירה לקישורים אליו. פתק ה-Markdown נשאר המקור, והרשומה היא העתק ש-Lumen מחליף
בכל פרסום.

## פרסום

1. פותחים את **פרסום אתר…** מלוח הפקודות ובוחרים פתקים.
2. מסמנים **לפרסם גם בחשבון ה-AT Protocol שלי**.
3. ממלאים **שם משתמש** (`name.bsky.social` או דומיין משלכם) ו-**App Password** (ב-Bluesky:
   *הגדרות ← פרטיות ואבטחה ← App passwords*). לעולם לא את הסיסמה הראשית.
4. ממלאים את **כתובת האתר**, המקום שבו האתר הסטטי מוגש (למשל כתובת GitHub Pages).
5. **פרסום**. כל פתק מקבל רשומת מסמך עם כותרת, תקציר (ה-`description` מה-frontmatter, או
   תחילת הפסקה הראשונה), שפה וכיוון (פתק עברי מסומן מימין לשמאל), ותגיות.

הפתק שומר `atproto-document: at://…` ב-frontmatter. פרסום נוסף מחליף את אותה רשומה ולא יוצר
חדשה. **להסיר את הפתקים שנבחרו מה-AT Protocol** מוחק את הרשומות שלהם ואת השורה הזו, והפתקים
עצמם נשארים.

## הוכחה שהאתר שלכם

האתר ש-Lumen בונה כולל עכשיו:

- `/.well-known/site.standard.publication` עם כתובת ה-`at://` של הפרסום;
- תגית `<link rel="site.standard.document" href="at://…">` בכל דף שפורסם.

מעלים את האתר כרגיל (קובץ zip, או GitHub Pages), ובודקים אותו בכלי הבדיקה של Standard.site.

## הפדיברס (Mastodon, ‏WordPress, ‏Ghost) דרך Bridgy Fed

אין צורך להריץ שרת ActivityPub. מאז מרץ 2026 [Bridgy Fed](https://fed.brid.gy) מגשר מאמרי
Standard.site לפדיברס:

1. ב-Bluesky עוקבים אחרי `@ap.brid.gy`. Bridgy Fed מגשר אז את החשבון שלכם, והוא מופיע בפדיברס
   בשם `@yourhandle@bsky.brid.gy`.
2. מפרסמים מ-Lumen כמו למעלה. Bridgy Fed שולח כל מסמך חדש לעוקבים שלכם בפדיברס כמאמר, עם
   כותרת, תקציר וקישור לדף.
3. כדי להפסיק, חוסמים את `@ap.brid.gy` ב-Bluesky.

## פרטיות ואבטחה

- הקריאות יוצאות מהאפליקציה ישר לחשבון שלכם: חיפוש שם המשתמש (`bsky.social`), מסמך ה-DID
  (`plc.directory`) וה-PDS שלכם (`*.bsky.network`). הן קורות רק כשאתם מפרסמים או מסירים, ויומן
  הפרטיות מציג אותן.
- ה-App Password ואסימון החיבור נשמרים במאגר הסודות של המכשיר (מחזיק המפתחות של המערכת
  באפליקציית שולחן העבודה, אחסון מוצפן בדפדפן). הם לעולם לא נכתבים לכספת, ל-`localStorage` או
  ליומנים.
- גם PDS בשרת משלכם עובד, אחרי שהפריסה מוסיפה את הכתובת שלו ל-`connect-src` של האפליקציה (ראו
  אירוח עצמי).
