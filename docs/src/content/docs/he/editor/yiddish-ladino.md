מלבד עברית, Lumen מכיר עוד שתי שפות יהודיות: **יידיש** ו**לדינו** (ספרדית-יהודית).

## תגית שפה לפתק

כותבים `lang:` בראש הפתק (front matter):

```yaml
---
lang: yi        # יידיש
---
```

| תגית | שפה | כיוון |
|---|---|---|
| `yi` | יידיש | מימין לשמאל |
| `lad-Latn` | לדינו באותיות לטיניות (כתיב "אקי ירושלים") | משמאל לימין |
| `lad-Hebr` | לדינו באותיות עבריות | מימין לשמאל |
| `lad` | לדינו: ‏Lumen בוחר `lad-Latn` או `lad-Hebr` לפי האותיות של הפתק | |

פתק בכתיב של יידיש (אַ, אָ, ע כתנועה) מזוהה כיידיש גם בלי התגית. התגית נכנסת
לעורך, לתצוגה המקדימה ולייצוא HTML (`<html lang="yi">`), ולכן קוראי מסך,
מקפים וגופנים פועלים לפיה.

כל פסקה עדיין מקבלת את הכיוון של הטקסט שלה, כמו בכל פתק. שורה באנגלית בתוך
פתק ביידיש נקראת משמאל לימין.

יידיש ולדינו באותיות עבריות מוצגות בגופן עברי עם ניקוד מלא (Noto Sans Hebrew).
הוא מגיע עם Lumen ונטען רק בפתקים כאלה.

## איות יידיש

לוח הפקודות ← **איות יידיש: רשימת מילים (הורדה / הסרה)**.

רשימת המילים היא [hunspell-yi](https://github.com/alephreish/hunspell-yi),
של רפאל פינקל, שמחה טאַוב ואנדריי רוזנברג. היא בגודל 2.4MB, ברישיון GPL-3.0.
בגלל הרישיון הזה היא **לא חלק מ-Lumen**:
- ‏Lumen מוריד אותה רק כשמריצים את הפקודה, מגרסה קבועה.
- הוא בודק את טביעת ה-SHA-256 של הקובץ מול הערך הצפוי.
- הוא שומר את הרשימה רק במכשיר הזה.

כשהרשימה מותקנת, כל פסקה ביידיש נבדקת מולה, במכשיר עצמו, ופסקאות בעברית
נשארות עם בודק העברית. הרשימה כותבת YIVO בלי שתי הנקודות שאינן חובה (פ במקום
פֿ, יי במקום ייִ). ‏Lumen מקבל את שתי הצורות, ומציג כל הצעה כפי ש-YIVO כותב.

## תעתיק

בוחרים טקסט, ואז לוח הפקודות ← **תעתיק של הבחירה (יידיש, לדינו)**. בוחרים
אחד מאלה:

- **יידיש ← תעתיק YIVO**: ‏`ייִדיש איז אַ שפּראַך` ← `yidish iz a shprakh`.
- **תעתיק YIVO ← יידיש**: מוסיף אלף שתומה לפני תנועה בתחילת מילה, אותיות
  סופיות בסוף, ו-וּ ליד ו. מילים נפוצות ממקור עברי נשארות בכתיב העברי:
  `shabes` ← שבת, `mishpokhe` ← משפּחה.
- **לדינו: אותיות לטיניות ← אותיות עבריות**, לפי כתיב "אקי ירושלים":
  `djudio` ← ג׳ודיו, `mujer` ← מוז׳יר.
- **לדינו: אותיות עבריות ← אותיות לטיניות**. באותיות עבריות, י יכולה לסמן
  *e* או *i*, ו-ו יכולה לסמן *o* או *u*, ולכן Lumen אומר כמה תנועות נאלץ
  לנחש. כדאי לבדוק אותן.
