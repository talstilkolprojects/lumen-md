ארבע פעולות יומיומיות שמי שעובר מ-Obsidian 1.12 או מ-Heptabase מצפה להן. כולן עובדות על
המכשיר בלבד.

## שינוי גודל תמונה

בתצוגה המקדימה גוררים את קצה התמונה בסוף השורה (הקצה השמאלי בעברית, הימני באנגלית). כשמשחררים,
הרוחב נכתב לפתק: `![[photo.png]]` הופך ל-`![[photo.png|300]]`, ו-`![alt](photo.png)` הופך
ל-`![alt|300](photo.png)`.

**לחיצה כפולה על אותו קצה** מסירה את הגודל: הפתק חוזר ל-`![[photo.png]]` והתמונה לגודל שלה.
פרמטרים אחרים (`![[photo.png|כיתוב|300]]`) נשמרים.

## מחיקת הקבצים המצורפים של פתק יחד איתו

כשמוחקים פתק (או תיקייה) מעץ הקבצים, Lumen מחפש את הקבצים המצורפים שרק מה שנמחק מקשר אליהם:
תמונות, קובצי PDF וקבצים אחרים. ואז, לפי ההגדרה:

- **לשאול בכל פעם** (ברירת המחדל): חלון מציג אותם, ואפשר להעביר גם אותם לסל, להשאיר אותם, או
  להחליט פעם אחת ולתמיד.
- **להעביר גם אותם לסל**: בלי שאלה.
- **להשאיר אותם**: הקבצים המצורפים לא נוגעים בהם אף פעם.

ההגדרה נמצאת בתחתית חלון **סל המחזור**. קובץ מצורף שפתק אחר, קנבס או קובץ base מקשר אליו, או
אפילו רק מזכיר את שמו בטקסט, לא מוצע למחיקה אף פעם. שם ששני קבצים חולקים (`photo.png` בשתי
תיקיות) משאיר את שניהם.

הכול עובר לסל בצעד אחד, ולכן **ביטול** בהודעה או **Ctrl+Z** אחד מחזירים את הפתק ואת הקבצים
המצורפים שלו יחד, וחלון הסל יכול לשחזר אותם במשך 30 יום.

## העתקה כטקסט מעוצב

העתקה מעורך המקור שמה עכשיו שני דברים ב-clipboard: את ה-Markdown כטקסט פשוט, ועיבוד HTML.
הדבקה ב-Word, ב-Google Docs או במייל שומרת כותרות, הדגשה, נטוי, רשימות, קישורים, ציטוטים
ובלוקי קוד. כל פסקה נושאת את הכיוון שלה (`dir="rtl"` לעברית, `dir="ltr"` לאנגלית), כך שפתק
מעורב מודבק בכיוון הנכון. הדבקה בשדה טקסט פשוט או באפליקציית Markdown אחרת עדיין נותנת
Markdown.

**העתקת תמונה**: לחיצה ימנית על הטמעת תמונה (`![[photo.png]]`) בעורך המקור ובחירה ב**העתקת
תמונה**. התמונה עוברת ל-clipboard כ-PNG. Shift ולחיצה ימנית פותחים את התפריט של הדפדפן.

## חיפוש, מיון וקיפול ב-backlinks

חלון ה-backlinks מקבץ את הקישורים לפי הפתק שממנו הם באים, עם מספר לכל פתק.

- **חיפוש** מסנן לפי שם הפתק או הנתיב שלו, או לפי הטקסט שסביב הקישור. אותיות גדולות וניקוד לא
  משנים.
- **מיון** לפי שם או לפי תאריך השינוי האחרון (החדש קודם). הבחירה נשמרת במכשיר.
- לחיצה על שם פתק **מקפלת** אותו; **לקפל הכול** / **לפתוח הכול** מקפלים את כל הקבוצות.

החיפוש בכספת (**⌘K ← חיפוש בכספת…**) מוצא גם טקסט בתוך בלוקי קוד ובתוך פריטי רשימה מקופלים
בעורך: הקיפול רק מסתיר אותם במסך.
