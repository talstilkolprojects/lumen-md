## גזירה מתוך Lumen

שתי פקודות שומרות דף בכספת כפתק נקי, עם המקור והתאריך ב-front matter:

- `⌘K → Clip a web page…` — מדביקים כתובת; Lumen מביאה את הדף ושומרת את
  המאמר (`<article>` / `<main>`), בלי ניווט, פרסומות, טפסים וסקריפטים.
  הבאת אתר כלשהו דורשת את שירות המחקר ([מחקר](/he/ai/research/)); בלעדיו
  אפשר לגזור רק אתרים שמדיניות האבטחה של האפליקציה כבר מתירה, ו-Lumen אומרת
  זאת.
- `⌘K → Clip from clipboard` — קודם מעתיקים משהו מהדף; ה-HTML (או הטקסט)
  שהועתק הופך לפתק.

הגזירים נכנסים לתיקייה **ספרייה** (**Library** כשהממשק באנגלית), מקבלים
מספר כשהשם תפוס, ונפתחים בלשונית חדשה.

```yaml
---
title: "How CRDTs Work"
source: "https://martin.kleppmann.com/2020/07/06/crdt-hard-parts.html"
clipped: 2026-04-26
---
```

## תוסף הדפדפן

גוזר הרשת של Lumen הוא תוסף ל-Chrome / Edge ‏(Manifest V3). התוסף שולח את
הדף ל-Lumen, ו-**Lumen** הופך אותו לפתק. החילוץ נעשה באפליקציה, כך שהגזיר
יוצא אותו דבר בכל דרך שבה הוא מגיע.

### התקנה (מצב מפתחים)

1. ‏`chrome://extensions/` ← הפעילו **Developer mode**
2. ‏**Load unpacked** ← בחרו את התיקייה `extension/` של המאגר
3. פתחו את **ההגדרות** של התוסף: כתובת ה-Lumen שלכם (ברירת מחדל
   `http://localhost:5173`), או **אפליקציית Lumen לשולחן העבודה**.

### שימוש

- **שמירת הדף כולו**: הכפתור בסרגל הכלים, או קליק ימני ← **Clip to Lumen**.
- **שמירת הקטע המסומן בלבד**: סמנו טקסט קודם. רק הקטע הופך לפתק.
- **מדגש**: סרגל הכלים ← **Highlighter on/off**, ואז סמנו קטעים בדף. הם נשמרים
  לפי כתובת, מסומנים שוב כשחוזרים לדף, ונכנסים לראש הפתק (כציטוטי `==הדגשה==`)
  בגזיר הבא.

### איך הגזיר מגיע ל-Lumen

| איפה Lumen רץ | איך |
|---|---|
| לשונית בדפדפן | התוסף מוצא (או פותח) את לשונית Lumen ומעביר לדף את הגזיר ב-`postMessage`. האפליקציה מקבלת הודעות רק מהחלון ומהמקור שלה. |
| אפליקציית שולחן העבודה | קישור `lumen://clip?…`. אם Lumen כבר פתוח, החלון הפתוח מקבל אותו. |

שום דבר לא מועלה לשום מקום: אין שרת גזירה.

## מה יש בגזיר

החלק הקריא של הדף, ש-[Defuddle](https://github.com/kepano/defuddle) ‏(MIT) מוצא,
עם Mozilla Readability ‏(Apache-2.0) כגיבוי, ו-Turndown ‏(MIT) ממיר ל-Markdown.
מאפייני הפתק: `title`, `source`, `author`, `published`, `clipped`, `tags`.
קישורים ותמונות מפנים לדף המקורי. הגזירים נשמרים בתיקיית הספרייה
(`ספרייה/` כש-Lumen בעברית, `Library/` אחרת).

### תבניות לפי אתר

| אתר | תיקייה | תוספת |
|---|---|---|
| ויקיפדיה (כל שפה) | `Wikipedia` | `license: CC BY-SA 4.0`, `summary` |
| ynet | `ynet` | `summary`, `topics`, `tags: [clip, news]` |
| הארץ | `Haaretz` | `summary`, `topics`, `tags: [clip, news]` |
| YouTube | `YouTube` | `channel`, `published`, `summary`; התמלול כשחלונית התמלול פתוחה |
| arXiv | `arXiv` | `authors`, `arxiv`, `published`, `pdf`, `contribution`; התקציר |
| מאגרי GitHub | `GitHub` | `description`, `purpose` |
| דפים שמסומנים כ-`Recipe` של schema.org | `Recipes` | `tags: [clip, recipe]` |

התבנית נבחרת לפי הטריגרים שלה: תחילת כתובת, `/ביטוי רגולרי/` או `schema:@Type`.
ההתאמה הראשונה קובעת.

מלבד `{{title}}`, `{{url}}`, `{{content}}` ושאר המשתנים, תבנית יכולה לקרוא מהדף עם `{{meta:name}}` (תגית `<meta>` לפי name, property או itemprop; כמה תגיות באותו שם מצורפות יחד) ועם `{{selector:css}}` (הטקסט של האלמנטים שבורר CSS בוחר).

## פרשן: שדות שמודל מקומי ממלא

תבנית יכולה לשאול שאלות על הדף: `{{"סיכום במשפט אחד"}}`, `{{"שלושה נושאים מרכזיים"|lower}}`. כשגזיר משתמש בתבנית כזו, Lumen שואל **מודל במכשיר שלך** — Ollama במחשב הזה או ברשת המקומית, או המודל שבדפדפן אם הוא כבר טעון — וכותב את התשובות בפתק. אין מסלול לענן: בשום מדיניות AI הפרשן לא שולח דף לספק AI. כשאין מודל מקומי פועל, השדות האלה נשארים ריקים והגזיר נשמר כרגיל.

- המודל קורא רק את מה שהתבנית מצביעה עליו (בוררי ה-`context` שלה: התקציר ב-arXiv, הפתיח בוויקיפדיה, התמלול ב-YouTube), עד כ-6,000 תווים, כך שחלון של מודל קטן מספיק. באפליקציית הדסקטופ אין צורך להגדיר `OLLAMA_ORIGINS` או גודל הקשר.
- כל השאלות של תבנית נשלחות בבקשה אחת.
- טקסט הדף עובר את שומר הזרקת ה-prompt לפני שהמודל רואה אותו, מסומן כמידע מבחוץ, וכל תשובה נבדקת שוב לפני שהיא נכתבת בפתק.

## בטיחות

גזיר הוא תוכן מבחוץ. השדה `source:` מסמן את הפתק כלא-מהימן בעיני סוכני ה-AI.
לפני שהפתק נשמר, טקסט מוסתר (תווים ברוחב אפס, תווי tag בלתי נראים, HTML מוסתר)
וקטעים שנראים כמו הוראות ("התעלם מכל ההוראות…") מוסרים או מסומנים בגלוי,
עם אזהרה בראש הפתק.

## דיוק

על סט הזהב של הגוזר (תוכנית 7.10: 20 דפים עם פרסומות, באנרים של עוגיות,
כפתורי שיתוף, תגובות ותחתיות סביב מאמר בנחלת הכלל), הגזיר חייב לכלול את
הכותרת המדויקת, כל פסקה בסדר הנכון ובלי רעש ב-90% מהדפים לפחות. הבדיקה רצה
בכל שינוי (`clipperGolden.test.ts`).

## פרטיות

הפקודות שבתוך האפליקציה מביאות רק את הדף שביקשתם (דרך שירות המחקר כשהוא
מוגדר). התוסף לא שולח שום דבר ברשת: הוא קורא את הדף שאתם גוזרים ומעביר אותו
ללשונית ה-Lumen שלכם (`postMessage`) או לאפליקציה לשולחן העבודה (קישור
`lumen://clip`). הבקשה היחידה שלו היא פתיחת כתובת ה-Lumen שלכם כשאין לשונית
Lumen פתוחה. בלי מעקב ובלי טלמטריה. המניפסט שלו הוא
[`extension/manifest.json`](https://github.com/talstilkol/lumen-md/blob/main/extension/manifest.json).
