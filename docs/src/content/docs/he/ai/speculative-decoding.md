מגרסה 0.34, ‏Ollama מפעיל כברירת מחדל **פענוח ספקולטיבי** במודלים שמגיעים עם
ראש חיזוי (Qwen 3.6, ‏Qwen 3.8, ‏Gemma 4). זה יכול להאיץ את התשובות פי 1.3–2.4.
דווחו שתי בעיות: הפלט לא תמיד זהה בין ריצה לריצה, גם בטמפרטורה 0, ובמודל אחד
(qwen3.8) התשובות נעשו *איטיות* בערך פי ארבעה.

מה Lumen עושה:

- **מודד כל מודל פעם אחת לכל גרסת Ollama.** אחרי שמודל עונה בפעם הראשונה,
  Lumen מודד ברקע תשובה קצרה עם ברירת המחדל של Ollama ובלי ספקולציה
  (`draft_num_predict 0`).
- **משאיר את זה רק איפה שזה עוזר.** אם ברירת המחדל מהירה בפחות מ-10%, ‏Lumen
  מכבה את זה למודל הזה. כך הבחירה האוטומטית אף פעם לא איטית מהכיבוי.
- **מציג את המספרים** ברופא ה-AI (⌘K ← *AI doctor*), תחת *פענוח ספקולטיבי*,
  למשל `qwen3.6:27b: 48 → 115 tok/s (×2.4, on)`.
- **מכבה את זה ב-eval.** ‏`npm run eval:*` ו-`npm run models:day` שולחים
  `draft_num_predict 0` בכל בקשה ורושמים את גרסת Ollama ליד התוצאות, כדי שאפשר
  יהיה לשחזר ציון.
- **אף פעם לא מציע מודל טיוטה חיצוני.** מודל שלא מתאים האט את התשובות ב-73%
  בדיווחים.

כדי למדוד במחשב שלך מהטרמינל:

```bash
node scripts/ollama-speculative.mjs measure          # tok/s עם ובלי, לכל מודל
node scripts/ollama-speculative.mjs repro --model qwen3.6:27b   # זהה בבייט עם ההצמדה?
```
