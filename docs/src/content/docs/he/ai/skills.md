**מיומנות** היא זרימת עבודה שכותבים פעם אחת ומריצים עם `/`: ״סכם את מה
שקראתי השבוע״, ״מיין את ה-inbox״, ״בדוק את הציטוטים בפתק הזה״. זו תיקייה בכספת
עם קובץ `SKILL.md` בפורמט הפתוח של
[Agent Skills](https://agentskills.io/specification), ולכן אותו קובץ עובד גם
ב-Claude Code וב-Codex.

## הרצת מיומנות

- ב**חלון ה-AI** הקלד `/`: המיומנויות מופיעות מתחת לתיבה. בחר אחת, הוסף אחרי
  השם מה שאתה רוצה (`/sort-inbox רק הפתקים של השבוע`) ולחץ Enter.
- ב**סרגל הפקודות** (⌘K / Ctrl+K) הקלד `/` כדי לראות רק את המיומנויות.

המיומנות רצה על הפתק הפתוח דרך זמן הריצה של הסוכנים, קודם על המודל המקומי.
התשובה שלה, וכל שינוי שהיא מציעה, מחכים ב**מסך האישור**: שום דבר לא נכתב עד
שתאשר.

## מיומנויות התחלה

ב-Lumen יש שש, בעברית:

| מיומנות | מה היא עושה |
| --- | --- |
| `/weekly-reading` — סכם את מה שקראתי השבוע | מסכמת את הפתקים, הגזירים וההדגשות של 7 הימים האחרונים, עם קישורים |
| `/sort-inbox` — מיין את ה-inbox | מציעה תגיות ותיקייה לכל פתק ב-`inbox/` |
| `/book-breakdown` — פרק ספר לפרקים וכרטיסים | מציעה פתק לכל פרק, עם כרטיסי שאלה–תשובה |
| `/similar-notes` — מצא פתקים דומים | מציגה פתקים קשורים, עם שורה שמסבירה למה |
| `/literature-matrix` — הכן מטריצת ספרות | מציעה טבלה: מקור, שאלה, שיטה, ממצאים, מגבלות |
| `/check-citations` — בדוק ציטוטים | בודקת כל ציטוט מול פתק המקור שלו |

## כתיבת מיומנות משלך

צור `.lumen/skills/<שם>/SKILL.md` בכספת:

```markdown
---
name: meeting-actions
description: List the action items of the open meeting note, with owners. Use after a meeting.
allowed-tools: get_document
metadata:
  title-he: משימות מהפגישה
---
1. קרא את הפתק הפתוח.
2. רשום כל משימה כ-״- [ ] מי: מה (עד מתי)״.
```

- `name`: אותיות לטיניות קטנות, ספרות ומקפים בודדים, כמו שם התיקייה.
- `description`: מה המיומנות עושה ומתי להשתמש בה.
- `allowed-tools`: הכלים היחידים שהמיומנות מקבלת. של Lumen: `read_file`,
  `write_file`, `list_files`, `search_workspace`, `get_frontmatter`,
  `set_frontmatter`, `list_tags`, `get_document`, `get_selection`,
  `get_headings`, `replace_range` וכלי הבדיקה. שמות של Claude Code ממופים
  אליהם (`Read`, `Write`, `Edit`, `Grep`, `Glob`). קריאה לכל כלי אחר נחסמת.
  מיומנות אף פעם לא מקבלת כלי רשת, Python או git.
- מיומנות בכספת שלך עם שם של מיומנות התחלה מחליפה אותה.

## מיומנויות של אחרים

מיומנות שמגיעה עם תוסף, או מכספת שמישהו שיתף איתך, מסומנת **לא מהימנה**. בפעם
הראשונה שכל גרסה שלה רצה, Lumen מראה מאיפה היא הגיעה ואילו כלים היא מבקשת,
ומריץ אותה רק אם אישרת. ההוראות שלה עוברות את שומר ה-injection, וכל כתיבה או
קריאת רשת שלה מבקשת ממך אישור נוסף, מעבר למסך האישור.

## lumen-skills: ‏Lumen לסוכנים חיצוניים

`packages/lumen-skills` (‏MIT) מלמד את Claude Code, ‏Codex וסוכנים אחרים את
הפורמטים של Lumen: תצוגות `.base`, ‏frontmatter, ניקוד, הפניות לספריא וציטוט
משפטי ישראלי. העתק את התיקיות שלו ל-`~/.claude/skills/` (או לתיקיית
המיומנויות של הסוכן שלך).
