## ייצוא מ-Notion

1. ב-Notion: **Settings ← Export** (לדף בודד: **⋯ ← Export**).
2. בוחרים **Markdown & CSV**, כוללים דפי משנה, ומורידים את ה-zip.

## מביאים ל-Lumen

`⌘K → Import notes from another app (Obsidian, Notion, Evernote, Bear, Keep, Logseq, OneNote…)…`, ובוחרים את
ה-zip כמו שהגיע. ‏Lumen מזהה ייצוא של Notion לפי המזהים בני 32 התווים
ש-Notion מוסיפה לכל שם קובץ, ואז:

- מסירה את המזהים משמות הקבצים והתיקיות (`Plans 1a2b….md` ← `Plans.md`);
- משכתבת את הקישורים בין הדפים לשמות החדשים, כולל `#כותרות`;
- ממספרת שני דפים שיוצאים עם אותו שם (`Page 2.md`) ושומרת שהקישורים יפנו
  לנכון;
- מייבאת הכול לתיקייה חדשה, `Imported/<שם>`, ואף פעם לא על פתק קיים.

## מה משתנה

| ב-Notion | ב-Lumen |
|---|---|
| דפים ודפי משנה | קובצי Markdown ותיקיות |
| מסדי נתונים | קובץ `.csv` לכל מסד, ליד תיקייה של השורות שלו; פותחים את ה-CSV כטבלה, או בונים [תצוגת מסד נתונים](/he/workspace/database-views/) מעל השורות |
| בלוקים מתקפלים, הדגשות | רשימות וציטוטים של Markdown |
| הערות, היסטוריית דף, הרשאות | לא נמצאים בייצוא |

## מסדי נתונים: מה עובר

עשרים סוגים של תוכן במסדי נתונים של Notion, כל אחד נבדק אחרי ייבוא (`src/__tests__/notionScenarios.test.ts`, ‏20 מתוך 20 עוברים). מה ש-Notion שומר רק בתוכו, ה*הגדרות* של נוסחאות ו-rollups, עובר כערכים, ודוח הייבוא אומר זאת לכל עמודה כזו. אם צריך אותה חיה, מוסיפים את הנוסחה שוב כעמודת נוסחה בקובץ ה-base.

| | בייצוא | אחרי הייבוא |
| --- | --- | --- |
| 1 | מסד נתונים פשוט: טקסט, בחירה, מספר | אותן עמודות, באותו סדר, בקובץ `.base`; כל שורה פתק עם ערכים מסוגם |
| 2 | מסד נתונים ועמודות בעברית | שמות, תיקיות ומאפיינים בעברית כמו שהם |
| 3 | תיבת סימון | `Yes` / `No` ← `true` / `false` |
| 4 | מספרים עם אלפים או מטבע | `$1,200.00`, ‏`₪45` ← מספרים |
| 5 | אחוזים | `45%` ← `0.45`, המספר ש-Notion שומר |
| 6 | תאריכים ותאריך עם שעה | תאריכי ISO שה-base ממיין ומסנן |
| 7 | טווח תאריכים | ההתחלה בעמודה, הסוף ב-`<עמודה> end` |
| 8 | בחירה מרובה | נשמר כמו ש-Notion כותב (`a, b`); `contains` מוצא כל ערך |
| 9 | Relation למסד נתונים אחר | רשימת `[[קישורים]]` לפתקים שיובאו |
| 10 | Relation כקישורי notion.so | גם `[[קישורים]]` |
| 11 | Rollup ‏(Markdown & CSV) | הערכים שלו, כמספרים |
| 12 | נוסחה (ייצוא HTML) | הערכים שלה; הדוח אומר שהנוסחה עצמה לא הגיעה |
| 13 | Rollup ‏(ייצוא HTML) | הערכים שלו; הדוח מציין את ה-rollup |
| 14 | נוסחה עם ערכי טקסט | הטקסט כמו שהוצג |
| 15 | URL, ‏דוא״ל, טלפון | טקסט, בלי שינוי |
| 16 | אדם, Created by | השמות כטקסט |
| 17 | זמן יצירה / עריכה אחרונה | תאריכים עם שעה |
| 18 | דפי שורות עם תוכן | גוף הדף נשמר; התאים ש-Notion חוזר עליהם מתחת לכותרת עוברים ל-frontmatter |
| 19 | CSV של תצוגה לצד `_all.csv` | כל השורות מ-`_all.csv`; העותק של התצוגה מופיע ככפילות |
| 20 | עמודת מספרים עם תא חריג (`N/A`) | נשמר כטקסט, והדוח מציין את העמודה ואת התא |

## עברית

‏Notion שומרת כותרות בעברית בשמות הקבצים; Lumen משאירה אותן כמו שהן. כיוון
מימין לשמאל מזוהה לכל פסקה — ראו [עברית ומימין לשמאל](/he/editor/hebrew/).
