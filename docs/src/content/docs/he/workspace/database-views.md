הבלוק `database` הופך כל תיקייה של פתקי Markdown (עם front matter עקבי ב-YAML)
לאוסף שאפשר לשאול עליו — ומציג את התוצאה באחת מארבע תצוגות אינטראקטיביות.

## תייגו את הפתקים

מוסיפים front matter ב-YAML לכל פתק שרוצים לכלול:

```yaml
---
type: book
title: Invisible Cities
author: Italo Calvino
rating: 5
status: reading
cover: https://example.com/cover.jpg
---

(גוף…)
```

השדות לגמרי לבחירתכם — `type` הוא היחיד ש-Lumen מתייחסת אליו באופן מיוחד
(הוא מסנן השורות).

## הוסיפו בלוק database

```database
source: books/         # תיקייה תחת שורש סביבת העבודה
type: book             # סינון לפי frontmatter.type
view: kanban           # table | kanban | gallery | calendar
groupBy: status        # ל-kanban
sortBy: -rating        # '-' בהתחלה לסדר יורד
fields: [title, author, rating, status]
cover: cover           # לכרטיסי הגלריה
```

Lumen סורקת את סביבת העבודה, מוצאת כל פתק שבו `frontmatter.type` שווה ל-`book`,
ומציגה את התצוגה שביקשתם.

## סינון

`where:` — וגם תיבת ה**סינון** שמעל התצוגה — מקבלים ביטוי על ה-frontmatter,
בדומה ל-`WHERE` של Dataview:

- `AND` / `&&`, ‏`OR` / `||`, ‏`NOT` / `!` וסוגריים. `AND` קודם ל-`OR`.
- `=` `!=` `<` `<=` `>` `>=`. מספרים מושווים כמספרים, ותאריכי `YYYY-MM-DD`
  כתאריכים. `tags = "fav"` נכון כשהרשימה מכילה את `fav`.
- `contains(field, "x")`, ‏`startswith(…)`, ‏`endswith(…)`, ‏`empty(field)`.
- `file.name`, ‏`file.path`, ‏`file.folder` מתארים את הפתק עצמו.
- שמות שדות יכולים להיות בכל כתב: `סטטוס = "הושלם"`.

התפריטים **מיון** ו**קיבוץ** מסדרים את התצוגה מחדש ומחלקים אותה לקבוצות בלי
לשנות את ההגדרה.

## תצוגות

- **טבלה** — לחיצה על תא (או מיקוד עליו ו-F2) עורכת אותו; Enter שומר, Escape
  מבטל; תיבות סימון מתחלפות בלחיצה. בטבלה ארוכה מוצגות רק השורות שעל המסך.
  לחיצה על כותרת פותחת את הפתק.
- **כרטיסים** — תמונת שער + שדות מרכזיים. ‏`cover: <שם שדה>` קובע איזו כתובת
  מה-front matter תהיה תמונת הכרטיס.
- **Kanban** — עמודות לפי `groupBy`. גוררים כרטיס בידית שלו לעמודה אחרת כדי
  לשנות את המאפיין — או במקלדת: מיקוד על הידית, רווח, ← / →, רווח (Escape מבטל).
- **רשימה** — כותרות עם כמה שדות.
- **לוח שנה** — רשימת אירועים של כל פתק עם `dateField` שאפשר לפענח.
- **מפה** — סמן לכל פתק עם קואורדינטות (`location: "32.08, 34.78"`, או `lat` +
  `lng`). ראו [נוסחאות במסד נתונים ותצוגת מפה](/he/workspace/database-formulas/).

## עמודות נוסחה

`formulas:` מוסיף עמודות מחושבות — `total: price * qty`,
`late: if(due < today(), "late", "")` — שגם הסינון, המיון והקיבוץ יכולים
להשתמש בהן. התחביר וכל הפונקציות: [נוסחאות במסד נתונים ותצוגת
מפה](/he/workspace/database-formulas/).

## עריכה

עריכה משנה ערך אחד ב-frontmatter של פתק אחד — הערות, מירכאות, סדר המפתחות
וגוף הפתק נשארים בדיוק כמו שהיו. פתק שה-frontmatter שלו לא מפוענח לא נכתב
לעולם (מקבלים הודעה במקום). עריכה של הפתק הפתוח עוברת דרך העורך שלו, כך
שביטול עובד.

## עריכת פתקים רבים בבת אחת

מסמנים את התיבה בתחילת שורה בתצוגת **טבלה** (או על כרטיס בתצוגת **לוח**) כדי לבחור אותה.
**Shift** ולחיצה על תיבה אחרת בוחרים את כל השורות שביניהן. התיבה בכותרת בוחרת את כל הפתקים
שהמסנן מציג, ולחיצה נוספת מנקה. פתקים בטבלה של קובץ `.base` נבחרים באותה דרך.

כל עוד יש פתקים בחורים, נפתח סרגל מעל התצוגה:

- **שדה**: כל מאפיין, או שם חדש (גם בעברית: `שפה`, `תאריך עברי`).
- **פעולה**: *קביעת ערך*, *הוספת תגית*, *הסרת תגית*, *ניקוי השדה* או *שינוי הסוג*.
- הסרגל אומר כמה מהפתקים הבחורים ישתנו, לפני שמחילים.

**לשנות N פתקים** כותב את ה-frontmatter של כל פתק, ורק אותו: גוף הפתק, ההערות, המירכאות וסדר
שאר המאפיינים נשארים בייט אחר בייט, וכל קובץ נשמר בשמירה אטומית. פתק שה-frontmatter שלו לא
תקין, או שאי אפשר להמיר את הערך שלו בלי לאבד אותו (`ארבעים` למספר), נשאר כמו שהיה ונספר בהודעה.

כל השינוי הוא צעד אחד: **ביטול** בהודעה, או **Ctrl+Z** מחוץ לעורך, מחזירים את כל הפתקים. פתק
שערכתם שוב אחרי השינוי נשאר כמו שהשארתם אותו, וההודעה אומרת כמה כאלה היו.

## עדכון חי

עורכים פתק בלשונית אחרת ותצוגת מסד הנתונים מריצה את השאילתה מחדש
אוטומטית (אירוע `lumen-workspace-changed` מפעיל את הרענון).

## טיפים

- שלבו תצוגות — השאירו בלוק database גדול אחד בראש פתק מרכזי ועברו בין
  Kanban לגלריה בפס הלשוניות.
- שלבו עם **הוספה חכמה** — מדביקים מפרט YAML בשורה ריקה ו-Lumen עוטפת אותו
  בגדר `database` בשבילכם.
- בתוך הבלוק מסד הנתונים לקריאה בלבד. כדי לערוך שורה, לוחצים על הכותרת שלה
  ופותחים את הפתק עצמו.
