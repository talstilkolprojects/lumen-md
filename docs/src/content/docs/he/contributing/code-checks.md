הבדיקות האלה שומרות על הקוד ולא על פיצ'ר מסוים. כל אחת מציינת את הפקודה שמריצה
אותה מקומית.

## אין מחרוזות קשיחות

כל מחרוזת שמשתמש יכול לראות עוברת דרך `t()`, כדי שאפשר יהיה לתרגם אותה.
`npm run i18n:hardcoded` (`scripts/check-i18n-hardcoded.mjs`) קורא את עץ התחביר
של TypeScript ב-`src/`, כך שקוד, הערות ושמות מחלקות אף פעם לא נחשבים בטעות
לטקסט, ונכשל על:

| סוג | דוגמה |
|---|---|
| טקסט בין תגיות JSX | `<button>Save</button>` |
| מחרוזת מילולית כצאצא של JSX | `<p>{"Saved"}</p>` |
| מחרוזת מילולית במאפיין גלוי | `aria-label="Close"`, `title`, `placeholder`, `alt`, `label` |
| מחרוזת מילולית שמועברת להודעה | `showAiToast("Saved")`, `alert("…")` |

רק מחרוזות עם מילים נחשבות: סמלים, מספרים, מקשים ושמות של מוצרים או פורמטים
(Markdown, GitHub, JSON) לא מתורגמים. חריגה אמיתית נושאת `i18n-allow: <סיבה>`
בהערה באותה שורה או בשורה שמעליה. הבדיקה היא חלק מ-`npm run i18n:check`, שכל
[בניית ענף](/he/contributing/checks/) מריצה.

## כיסוי בדיקות על כל src

`npm run test:coverage` מודד כל תיקייה של `src/`. רק שלושה סוגי קבצים נשארים
בחוץ, כל אחד מסיבה אחרת מ"קשה לבדוק": הבדיקות והעזרים שלהן, קובצי הצהרות
טיפוסים בלבד, ונקודת הכניסה `src/main.tsx`, שהייבוא שלה מפעיל טיימרים ומרכיב את
האפליקציה (כל מה שהיא מחברת מכוסה בנפרד). `npm run ci:local -- --coverage` מחיל
את השער על ריצה מקומית מלאה: לפחות 65% מהשורות.

## חוזה אחד לכל מאגר כספת

כל מקום שבו נשמרים פתקים, האחסון הפרטי של הדפדפן (OPFS), תיקייה שנבחרה בדפדפן,
התיקייה של אפליקציית שולחן העבודה, התיקיות בטלפון והמאגר שבזיכרון, מממש את אותו
ממשק `VaultBackend`. `src/__tests__/vaultBackend.contract.test.ts` מריץ חבילה
אחת על כולם, וגם על שכבת ההצפנה שמעל כל אחד: רשימה, קריאה, כתיבה, שינוי שם,
מחיקה, ואותן שגיאות לקובץ חסר או להתנגשות. מאגר חדש מצטרף בהוספת שורה אחת
לרשימת `backends` של החבילה, והוא גמור כשהחבילה הזו עוברת. מה שמשתמשים רואים
ממנו מתואר ב[הכספת בתיקייה](/he/workspace/vault-folder/).
