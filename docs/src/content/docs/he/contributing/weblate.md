את מחרוזות הממשק של Lumen אפשר לסקור ב-**Hosted Weblate**, פלטפורמת תרגום שמארחת
פרויקטים בקוד פתוח בחינם. דובר/ת השפה סוקר/ת ומתקן/ת מחרוזות בדפדפן. Weblate שולח את
השינויים בחזרה למאגר כבקשת משיכה, ו-`npm run i18n:check` עובר עליהם כמו שהם.

**ערבית קודם.** זו שפת ה-RTL השנייה בישראל, והמחרוזות שלה תורגמו במכונה. התדריך
לסוקרי הערבית נמצא ב-
[`i18n/weblate/arabic-reviewer-brief.md`](https://github.com/talstilkol/lumen-md/blob/main/i18n/weblate/arabic-reviewer-brief.md).

## למתרגמים

1. נכנסים ל-Hosted Weblate. אפשר עם חשבון GitHub.
2. פותחים את הפרויקט **Lumen** ובוחרים שפה.
3. עוברים על הרכיבים בסדר ש-`npm run i18n:weblate -- --queue <lang>` מדפיס. מחרוזות
   ההפעלה באות קודם: הן הממשק לפני שנפתח כל מסך אחר.
4. בכל מחרוזת: **מאשרים** אותה אם היא כתובה כמו שדובר/ת השפה היה כותב/ת, או מתקנים.
   כל `{placeholder}` נשאר בדיוק כמו שהוא. Weblate בודק גם את זה.

שפה יוצאת מ**בטא** אחרי שדובר/ת השפה סקר/ה אותה: 100% ממחרוזות ההפעלה בערבית,
ולפחות 50% בכל שפה אחרת. אז הסטטוס שלה משתנה ב-`src/i18n/review.ts` (ראו
[שפות בבטא](/he/contributing/translations/)).

## איך הסנכרון עובד

| כיוון | איך |
|---|---|
| מאגר ← Weblate | ‏Weblate קורא את `main` דרך האפליקציה Hosted Weblate GitHub App. מחרוזת אנגלית חדשה מופיעה אחרי שממזגים את `npm run i18n:fix`, שכותב מחדש גם את בסיס האנגלית. |
| ‏Weblate ← מאגר | ‏Weblate פותח בקשת משיכה עם קובצי `src/i18n/locales/<lang>/<domain>.json` שהשתנו. מתחזק/ת ממזג/ת אותה אחרי ש-`npm run i18n:check` ו-`npm run i18n:weblate` עוברים. |

יש **רכיב אחד לכל תחום** (`cmd`, ‏`common`, ‏`ai`, ‏`editor`, ‏`files`, ‏`settings`,
‏`toast`, ‏`canvas`), וכל אחד מתאים לקובץ אחד לכל שפה.

ההגדרות נמצאות ב-`i18n/weblate/config.json`. הפקודה `npm run i18n:weblate -- --print`
מדפיסה את מה שמזינים ב-Weblate. שלוש בחירות בהן חשובות:

- **בסיס האנגלית הוא `i18n/weblate/en/<area>.json`**, ולא `src/i18n/locales/en/`.
  האפליקציה שולחת את המחרוזות האנגליות של מסכים שנטענים בעצלות בנפרד ממחרוזות
  ההפעלה, אבל בכל שפה אחרת שתיהן באותו קובץ. תוסף הניקוי של Weblate שומר רק את המפתחות
  שבבסיס, ולכן בסיס בלי המחרוזות העצלות היה מוחק את התרגומים שלהן.
  `node scripts/weblate.mjs --write` בונה את הבסיס משתיהן, ו-`npm run i18n:fix` מריץ אותו.
- **JSON כמו שהמבנה כותב אותו**: הפורמט "JSON file" עם הפרמטרים `json_indent: 2`
  ו-`json_sort_keys: case_sensitive`, רווחים, ובלי מפרידים דחוסים. Weblate כותב JSON
  עם translate-toolkit, שמשתמש ב-`json.dumps` של Python, עם `ensure_ascii` כבוי ושורה
  חדשה בסוף. עם הפרמטרים האלה כל 56 קובצי התרגום יוצאים זהים בית אחר בית. כל המפתחות
  הם ASCII, ולכן המיון של Python והמיון של JavaScript מסכימים.
- **התוסף "Remove blank strings".** הממשק מציג תרגום ריק כריק: `""` לא חוזר לאנגלית.
  `npm run i18n:weblate` דוחה ערך ריק.

## למתחזק: הקמה חד-פעמית

1. מבקשים אירוח חינמי (libre) ב-Hosted Weblate למאגר הציבורי `talstilkol/lumen-md`
   ‏(MIT). האירוח החינמי של Weblate מיועד לפרויקטים עם רישיון ש-OSI מאשר או ש-FSF מכיר
   כחופשי, שהקוד שלהם ציבורי.
2. מתקינים את **Hosted Weblate GitHub App** על `talstilkol/lumen-md` בלבד.
3. יוצרים את הפרויקט `lumen-md` ואת 8 הרכיבים לפי `npm run i18n:weblate -- --print`,
   מפעילים סקירות ומוסיפים את שני תוספי הניקוי.
4. מבקשים מסוקרי הערבית להתחיל, עם התדריך.
