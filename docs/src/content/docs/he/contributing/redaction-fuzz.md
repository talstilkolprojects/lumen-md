מצב עיתונאי מבטיח שקטע `<redact>` שהתצוגה המקדימה מצללת נעלם מכל ייצוא.
ביקורות 6 ו-8 מצאו דליפות אמיתיות שהמבחנים הרגילים פספסו, ובכל פעם בעזרת
מחולל fuzz. המחוללים האלה נמצאים עכשיו בריפו ורצים כל לילה.

## מה רץ

`npm run fuzz:redaction` מריץ את `tests/fuzz/redaction/redaction.fuzz.ts`
עם 20,000 מקרים, שמתחלקים בין ארבעה מחוללים:

| מחולל | מקור | מה הוא בונה |
| --- | --- | --- |
| `tags` | ביקורת F-8 | גרסאות של תג `<redact>` בתוך הערות, מאפיינים, רכיבי טקסט גולמי ו-CDATA |
| `blocks` | ביקורת 6 | פתקים מבלוקים של Markdown: ציטוטים ורשימות בעומק שתיים, גדרות קוד, קוד מוזח, מתמטיקה, טבלאות, בלוקי HTML |
| `footnotes` | ביקורת 8 | `blocks` עם הערות שוליים והצעות CriticMarkup בין הבלוקים |
| `containers` | ביקורות 8 ו-R6 | דקדוק CommonMark רקורסיבי: מכלים בעומק ארבע, שורות עצלות, טאבים, כל שבעת סוגי בלוקי ה-HTML, כותרות setext, הגדרות הפניה, הנחיות, טבלאות, CRLF |

לכל פתק, האורקל מרנדר אותו כמו התצוגה המקדימה (`prepareCriticMarkup`,
‏micromark עם ההרחבות של התצוגה, מפענח ה-HTML של הדפדפן, ובלוק אחרי בלוק
כשהתצוגה עושה כך). הוא מונה את האסימונים שבתוך רכיבי `redact`, ואז בודק את
הטקסט של דלת הייצוא (`prepareForExportSync`). אסימון מוצלל שהייצוא משאיר
הוא דליפה.

## הזרע

הזרע הוא התאריך ב-UTC כמספר, למשל `20261114`. לילה תמיד מייצר את אותם
פתקים, ולכן אפשר לשחזר אותו:

```sh
npm run fuzz:redaction -- --night 20261114
```

‏`--n` משנה את מספר המקרים, ו-`--no-save` מריץ בלי לכתוב דבר.

## דליפה הופכת למבחן

כל דליפה ממוזערת: מוחקים שורות ואחר כך מילים, כל עוד היא עדיין דולפת.
הפתק הממוזער נוסף ל-`tests/fuzz/redaction/regressions.json`, והחבילה
הראשית מריצה שוב כל מקרה ב-`src/__tests__/redactionFuzzRegressions.test.ts`.
כך החבילה נכשלת עד שהדליפה מתוקנת, ונשארת מבחן גם אחר כך. עם `--commit`
המארח מבצע commit לקובץ בענף חדש `fuzz/redaction-<night>` עבור pull request.

הקובץ מתחיל עם 34 הדליפות שביקורות 6 ו-8 מצאו ב-#473. כולן דולפות ב-commit
שנבדק, ואף אחת לא דולפת עכשיו.

לדליפה ידועה שעדיין לא תוקנה יש שדה `open` עם שם הממצא. החבילה בודקת אז
שהיא *עדיין* דולפת, כך שמי שמתקן אותה מוחק את השדה והמקרה נשאר מבחן. הלילה
הראשון (20261114) מצא שתי דליפות כאלה במחולל `tags`: ‏`W8.8-F1` (תו CR בתוך
תג) ו-`W8.8-F2` (הערה שנפתחת בתוך תג סוגר).

## במארח השני

הדוח הלילי נכתב ל-`reports/nightly/fuzz-redaction.json`. המארח השני (W6.5)
מריץ את השלב וחותם את הדוח בקבלה שלו. קודי יציאה: 0 אין דליפה, 1 נמצאו
דליפות (ונשמרו), 2 ההרצה נשברה.
